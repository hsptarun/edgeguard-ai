# Testing

Run: `source .venv/bin/activate && pytest -v`

## What was actually run (development sandbox, Linux, Python 3.12)
Versions: streamlit 1.65.0, pandas 3.0.2, numpy 2.4.4, opencv-python-headless 4.13.0.92, matplotlib 3.10.8, pytest 9.1.1.

Result: **78 passed, 1 skipped** (79 collected), after adding R5 (loitering/dwell) and local login/signup. The skipped test is `test_real_model_runs_on_blank_frame`: PyTorch could not be installed in the sandbox (disk space), so **YOLO inference was NOT executed there**. Run it on your Mac - it is enabled automatically once the model and torch are present.

## Evaluation (generated by `python -m evaluation.evaluate`, seed 42)
Rule classifier, 93 synthetic scenarios (23 hand-written + 70 generated): TP 51, FP 0, TN 42, FN 0; precision/recall/F1 = 1.000; FPR 0.000; alert-count match 1.000.
**Interpretation:** the labels come from the written access policy and the generated cases are labelled by construction, so a perfect score shows the engine implements the policy consistently. It does not estimate real-world accuracy.

Detector (YOLO): **not measured**. Run `python -m evaluation.evaluate --video clip.mp4` on your Mac to obtain ms/frame and FPS; accuracy would need annotated footage, which this project does not include.
